# 단어장 업로드 학습 앱

바닐라 JavaScript로 만든 CSV/XLSX 단어 학습 웹앱입니다.

## 실행 방법

1. 압축을 풉니다.
2. `index.html` 파일을 브라우저에서 엽니다.
3. CSV 또는 XLSX 파일을 업로드합니다.

## 업로드 권장 형식

| 어휘/표현 | 품사 | 뜻 |
|---|---|---|
| disinfection | 명사 | 소독 |
| last | 동사 | 지속되다, 계속되다 |
| chemical | 명사 | 화학 약품, 화학 제품 |

## 주요 기능

- CSV/XLSX 업로드
- 컬럼 자동 매핑
- 단어장 생성
- 단어 목록 검색/필터
- 플래시카드 학습
- 객관식 퀴즈
- 오답 노트
- 학습 통계
- CSV 내보내기
- 전체 백업

## 참고

XLSX 파일 업로드는 SheetJS CDN을 사용합니다.
인터넷 연결이 없는 환경에서는 CSV 업로드를 사용하세요.
